## Required Environment Variables

| Variable | Description |
|---|---|
| `AGENT_NAME` | Licensed agent's full name |
| `AGENT_BROKERAGE` | Brokerage name |
| `AGENT_DRE` | DRE license number |
| `ANTHROPIC_API_KEY` | Claude Vision API key |
| `DECOR8_API_KEY` | Decor8 staging API key |
| `IMGBB_API_KEY` | ImgBB temporary image hosting |
| `NETLIFY_ACCESS_TOKEN` | For background function storage |
| `NETLIFY_SITE_ID` | Your site ID |

## What Smart Stage MLS™ Does

- AI virtual staging for vacant listings — powered by Decor8
- Claude Vision prompt generation with review modal
- Draft staging for iteration
- Final MLS-quality upscaled download with "VIRTUALLY STAGED" badge
- Side-by-side before/after download
- MetroList Rule 11.6.1 compliant watermark on all downloads
- DNA continuity across multi-room listings

## What Smart Stage MLS™ Does NOT Include

- AB 723 compliance storage or QR codes (upgrade to Smart Stage PRO™)
- Clean + Stage for occupied listings (PRO only)
- Property project management (PRO only)
- 3-year DRE record retention hosting (PRO only)
